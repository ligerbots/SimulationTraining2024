## Goals of this branch:
Implement [Coreo auto](https://choreo.autos/) paths in the [PathPlanner lib](https://pathplanner.dev/pathplannerlib.html) and side by side test the paths to see if Choreo autos run faster than PathPlanner autos _(the autos generated by the [path planner application](https://pathplanner.dev/home.html), not library)_ 

## What has been acheved so far:
[Coreo autos](https://choreo.autos/) have been successfully implemented in the [PathPlanner lib](https://pathplanner.dev/pathplannerlib.html) and according to the respective applications, the Choreo auto takes 2.00 seconds, and the PathPlanner path takes 2.52 seconds, making the Choreo path 0.52 seconds faster or 26% faster then the PathPlanner path.



# Setting up the simulation:

## 1. How to install 2025 beta WPILIB VS Code 

> **IMPORTANT**: _(**You must use this modified version of Visiual Studio code for the simulation to work**)_

1. Download 2025 beta WPILIB VS Code from [here](https://github.com/wpilibsuite/allwpilib/releases/tag/v2025.1.1-beta-2).
2. Open the package, and follow the install steps.

## 2. Running the Simulation with WPILib

1. Open this repo in 2025 beta WPILIB VS Code.
2. Press `Ctrl+Shift+P` to open the command palette.
3. Type `WPILib: Simulate Robot` and select it from the list.
4. Click through the models.
5. Change the robot's alliance to the Blue alliance & switch the robots mode into autonomous

## 3. Switching Between Choreo Auto and PathPlanner Auto

1. Open the robot code in 2025 beta WPILIB VS code
2. Navagate to `src/main/java/frc/robot/commands/ChoreoVSPathplannerAutoTest.java`
3. Set `choreoPathEnabled` to false to simulate the path planner path, and to true to simulate the choreo path.
